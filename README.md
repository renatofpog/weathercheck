# 🌤️ Descubra o Clima

Uma aplicação web simples, moderna e responsiva para consulta de previsão do tempo em tempo real, utilizando a API da OpenWeatherMap.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias web puras, sem a necessidade de frameworks complexos, focando na performance e semântica:

* **HTML5:** Estruturação semântica da aplicação.
* **CSS3:** Estilização moderna utilizando Flexbox, variáveis CSS e efeitos de `linear-gradient`.
* **JavaScript (ES6+):** Manipulação assíncrona do DOM utilizando `async/await` e consumo de API REST.
* **OpenWeatherMap API:** Serviço de terceiros utilizado para buscar dados climáticos em tempo real de qualquer cidade do mundo.

---

## 💡 Funcionalidades

* **Busca por Cidade:** O usuário digita o nome de qualquer cidade e obtém os dados instantaneamente.
* **Dados em Tempo Real:** Exibe o nome da cidade oficial, temperatura atual (em graus Celsius) e a descrição do clima em português (ex: "céu limpo", "chuva moderada").
* **Prevenção de Erros:** Tratamento de erros robusto (`try/catch`) para alertar o usuário caso a cidade não seja encontrada ou ocorra falha de conexão.
* **Design Responsivo:** Interface que se adapta perfeitamente a telas de celulares, tablets e desktops.
